# 中学生交互式光学设计编程项目

## How to Run

```bash
# Docker 运行（推荐）
docker-compose up --build -d

# 访问应用
# 用户端: http://localhost:8081

# 或直接用浏览器打开 frontend-user/index.html
```

## Services

| 服务 | 端口 | 说明 |
|------|------|------|
| frontend-user | 8081 | 光学设计交互应用 |

## 测试账号

本项目为纯前端应用，无需登录账号。

## 题目内容

制作一个面向中学生的交互式光学设计编程项目，要求以html格式开发 确保简洁易用 包含各种形状和材料的透镜 例如非球面透镜 低色散镜片 高折射率镜片等 具有可视化操控界面和2D光路实时渲染 系统应有第一次打开的引导界面和跨设备兼容性

## 项目介绍

面向中学生的交互式光学设计学习工具，通过可视化方式帮助学生理解透镜成像规律。

### 核心特性

- 透镜类型：凸透镜、凹透镜、平面透镜、非球面透镜
- 特殊材料：低色散镜片、高折射率镜片、普通玻璃
- 2D光路实时渲染（Canvas 2D API）
- 首次使用引导界面
- 跨设备响应式布局（手机、平板、电脑）

### 光路规律

- 凸透镜：光线向光轴会聚
- 凹透镜：光线向外发散
- 平面透镜：不偏折
- 非球面透镜：更精准会聚，消除球差

### 技术栈

HTML5 + CSS3 + JavaScript（原生无依赖）

### 引导状态

- 完成引导或点击“跳过引导”后，完成状态会保存在浏览器本地存储中，刷新或重新打开页面不会自动弹出。
- 点击右上角帮助只会重新查看引导，不会清除或修改已保存的完成状态。
- 未完成引导时会保存当前步骤，下次打开自动回到上次步骤。
- 点击引导中的“重置引导”会明确提示：清除记录后，下次打开页面会重新弹出引导。
- 纯前端应用没有账号和云端同步。可在引导中点击“复制恢复链接”，换浏览器、换设备或清理站点数据后打开该链接恢复到上次状态。
